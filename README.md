# TourPlanner

GitHub Link:
https://github.com/ViktoriaKluge/SwenTourPlanner

Angular-Webanwendung zur Planung und Verwaltung von Touren (Wandern, Laufen, Radfahren) mit interaktiver Kartenansicht.

## Features

- Touren erstellen, bearbeiten und verwalten
- Kategorien: Wandern, Laufen, Radfahren
- Interaktive Karte mit Start-/Endpunkt und Points of interest (poi) (Leaflet)
- Tourentagebuch mit Schwierigkeitsbewertung und Kommentaren
- Benutzeranmeldung

## Setup

```bash
npm install
ng serve
